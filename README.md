# 🍔 Hunger Fuel

Hunger Fuel is a university-level Software Engineering project designed to help users discover suitable restaurants through reviews, ratings, menus, deals, and discounts.

The platform brings restaurant information together in one place so users can make better dining decisions without searching across multiple websites.

## 📌 Project Overview

People often find it difficult to select a good restaurant because restaurant reviews, menus, prices, deals, and discounts are available on different platforms.

Hunger Fuel provides a simple solution where users can:

- Search for restaurants
- View restaurant information
- Read customer reviews
- Submit their own reviews
- Rate restaurants
- View restaurant menus
- Check available deals and discounts

Administrators can manage restaurant information, menus, reviews, ratings, deals, and discounts.

## 🎯 Project Objectives

- Help users select suitable restaurants.
- Provide restaurant reviews and ratings in one place.
- Allow users to view menus before visiting a restaurant.
- Inform users about available deals and discounts.
- Provide an easy-to-use interface.
- Allow administrators to manage restaurant data.
- Store restaurant and user information securely.

## ✨ Main Features

### User Features

- User registration
- User login
- Restaurant search
- View restaurant details
- View menus
- View deals and discounts
- Read reviews and ratings
- Submit restaurant reviews
- Give restaurant ratings

### Admin Features

- Add new restaurants
- Update restaurant information
- Delete restaurants
- Manage restaurant menus
- Add or remove deals
- Monitor user activity
- Remove inappropriate reviews

## 👥 User Roles

### Normal User

A normal user can search restaurants, view restaurant details, read reviews, submit reviews, give ratings, and check menus and offers.

### Administrator

An administrator can manage restaurant information, menus, deals, discounts, ratings, and reviews.

## 🛠️ Planned Technologies

- **Frontend:** HTML, CSS and JavaScript
- **Backend:** PHP or a similar server-side technology
- **Database:** MySQL

## 📋 Functional Requirements

The main functional requirements include:

1. User registration and login
2. Restaurant searching
3. Restaurant details viewing
4. Review submission
5. Rating submission
6. Menu viewing
7. Deals and discounts viewing
8. Restaurant management by admin
9. Review moderation by admin

## 🔒 Non-Functional Requirements

### Performance

- Website pages should load within approximately 3–5 seconds.
- Search results should be displayed quickly.
- The system should handle multiple reviews without significant performance issues.

### Security

- Users must log in using valid credentials.
- Passwords should be stored securely.
- Only administrators should access management features.
- User information should not be shared with unauthorized parties.

### Usability

- The interface should be simple and understandable.
- Buttons and navigation options should be clearly visible.
- The website should be usable by people with basic technical knowledge.

### Reliability

- The system should operate without frequent crashes.
- Restaurant, review, rating, menu, and deal information should be stored correctly.
- The system should avoid accidental data deletion.

## 🗄️ Main Database Entities

The system contains the following main entities:

- User
- Admin
- Restaurant
- Review
- Rating

These entities are connected through relationships such as:

- A user writes reviews.
- A user gives ratings.
- A restaurant receives reviews and ratings.
- An administrator manages restaurants and reviews.
